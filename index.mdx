Welcome to the Pocoma developer documentation. Pocoma is a Spring Boot REST API for managing shared expense pots: users create pots, add participants, record expenses, and the system computes balances via an async projection pipeline. These docs cover the architecture, module layout, and everything you need to understand the codebase and confidently add new features.

## Get Up and Running

<Steps>
  <Step title="Clone and build">
    Clone the repository, then build all modules from the `app/` directory:

    ```bash
    git clone https://github.com/kartaguez/pocoma.git
    cd pocoma/app
    ./mvnw -pl runtime-monolith -am install -DskipTests
    ```
  </Step>
  <Step title="Run the monolith">
    Start the all-in-one monolith with the embedded H2 database — no external dependencies needed:

    ```bash
    ./mvnw -pl runtime-monolith spring-boot:run
    ```

    The API is available at `http://localhost:8080`. To use PostgreSQL instead, see the [Architecture Overview](/architecture-overview) for split-runtime and Docker Compose modes.
  </Step>
  <Step title="Make your first API call">
    Create a pot by providing a name and your user ID in the `X-User-Id` header:

    ```bash
    curl -s -X POST http://localhost:8080/pots \
      -H "Content-Type: application/json" \
      -H "X-User-Id: user-1" \
      -d '{"name": "Weekend Trip"}'
    ```

    The response includes a `potId` and an initial `version`. Pass `expectedVersion` on every subsequent write to protect against concurrent updates.
  </Step>
</Steps>
